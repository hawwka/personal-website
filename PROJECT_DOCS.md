# Документация проекта: Personal Website

Личный вебсайт-портфолио в стиле landing page. Проект спроектирован с упором на чистую архитектуру, высокую производительность и модульность.

## Технологический стек

Проект использует современные инструменты экосистемы React, оптимизированные для работы с AI-агентами.

### Core (Ядро)
* **Next.js 15 (App Router)** — основной фреймворк. Обеспечивает Server-Side Rendering (SSR) и Static Site Generation (SSG) из коробки. File-based routing делает структуру проекта предсказуемой.
* **TypeScript** — язык программирования. Строгая типизация (`Strict Mode`) используется для минимизации ошибок и автодокументации кода.
* **React 19** — библиотека для построения пользовательских интерфейсов.

### Styling & UI (Внешний вид)
* **Tailwind CSS v4** — утилитарный CSS-фреймворк. Используется для всей стилизации. Позволяет держать стили прямо в компонентах, избегая конфликтов и глобального CSS-контекста.
* **shadcn/ui (на базе Radix UI)** — набор доступных (accessible) и кастомизируемых UI-примитивов (кнопки, карточки, инпуты). Компоненты копируются прямо в проект (`src/components/ui/`), что дает полный контроль над их кодом.
* **next-themes** — библиотека для управления цветовыми темами (светлая / темная) с поддержкой системных настроек пользователя.

### Animations (Анимации)
* **Framer Motion** — библиотека для декларативных анимаций. Используется для всех визуальных эффектов: параллакс при скролле, появление элементов при попадании во viewport, а также бесконечные фоновые анимации.

### Quality Assurance (Тестирование и качество)
* **Vitest + React Testing Library (RTL)** — инструменты для Unit и Integration тестирования. Проверяют логику кастомных хуков и рендер изолированных компонентов.
* **Playwright** — фреймворк для End-to-End (E2E) тестирования. Проверяет критические пользовательские пути в реальном браузере (навигация, адаптивность, формы).
* **ESLint + Prettier** — статический анализ и форматирование кода.

### Deployment (Развертывание)
* **Vercel** — платформа для хостинга. Обеспечивает zero-config деплой для Next.js приложений, автоматические превью-сборки для PR и глобальную CDN.
